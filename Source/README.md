# Source/

Здесь размещаются оригиналы фотографий, которые попадут в галерею.

## Структура

Файлы изображений организуются по категориям и подкатегориям:

```
Source/
├── Wildlife/                  # Категория (папка)
│   ├── Bears/                 # Подкатегория
│   │   └── bear_photo.jpg
│   ├── Foxes/
│   └── Seals/
├── Portrait/
├── Portfolio/
└── ...
```

## Правила

- **Поддерживаемые форматы**: JPG, JPEG, PNG
- **Категории** определяются по имени папки (через `categories.json`)
- **Подкатегории** — это вложенные папки внутри категории
- **Рейтинг** (опционально): создайте файл `<имя>.jpg.rating` рядом с фото и запишите число от 1 до 5, например `echo 5 > bear_photo.jpg.rating`

## Запуск сборки

```bash
./build_gallery.sh ./Source ./Web
```
